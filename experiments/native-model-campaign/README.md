# Compiled native-model response campaign

This dedicated SDK experiment generates new **synthetic/conditional predictions**
from six distinct production compiled models: canonical exponential quintessence,
self-accelerating dust DGP, NFW halo/conditional thin lens, pressureless decay to
massless radiation, nonflat GR FLRW, and finite-mass Hernquist sphere. It fits no
observations, evaluates no likelihood, and changes no historical CLASS/SDK pin.
[request.json](request.json) freezes the new source revision, parameter sweeps,
scientific roles, numerical comparison allowances and bounded resource policy.
Its blocked generic packet status means the single-request runner has no route;
the separately reviewed controller below owns this actual native SDK campaign.

All production equations live in Irreducible. Python performs admission, process
control, retained-output comparison and plotting only. The C++ consumer calls the
actual installed static library, reports each model's native identity, supplied
parameters, units, numerical/status diagnostics and default/refined outputs.
It retains deliberately tested singular/unsupported controls separately.

The root build must be clean at the request's exact committed revision. Use its
actual production Release build manifest and fresh full installed SDK:

```sh
python -B experiments/native-model-campaign/controller.py \
  --sdk /absolute/new-model-sdk --engine-source /absolute/clean-irred-source \
  --build-manifest /absolute/build-manifest-release.json \
  --attempt "$PWD/results/native-model-campaign/UNIQUE" --profile quick
```

Each attempt is new. The controller verifies the full installed inventory and
all build-manifest scientific source hashes before and after compiling/running,
records actual library/consumer/compiler identities, applies one-thread limits,
and preserves refused/failing prefixes. Changing source needs a newly reviewed
request identity, never a historical repin. `broader` retains the same parameter
families and assumptions with denser coordinate sampling; it adds no probe.

Before comparisons, default/refined relative differences receive 2e-6; w_phi
absolute 1e-5; distances additionally 1e-4 Mpc; halo mass/density/lens quantities
1e-7 relative. Exactly zero quantities use the declared 1e-10 absolute floor.
Native policy budgets and these empirical final-response budgets are distinct.
A refused output is retained and withholds its comparison; no row is silently
removed and no allowance is weakened. No certified global bound is inferred.

Quintessence finite anchor values are not attractors. DGP lacks radiation,
complete five-dimensional perturbations and nonlinear screening; the known
self-accelerating ghost caveat remains. NFW's untruncated mass and supplied
Sigma_critical/D_l are distinct from Hernquist's finite mass and supplied SI G.
DCDM H_i is an initial inverse-second rate, not H0, and no source shooting or
perturbations is supplied. Curved distances carry actual spatial geometry;
they do not determine a lens's source mass, calibration or two-epoch distances.
Model/refinement plots compare these roles explicitly, never fit them to
invented data or combine their unrelated output scales.

Completed and failed full attempt evidence is saved through the existing named
S3 route, dry-run admission, exact-version object readback, manifest last and
fresh-directory restoration. The source-review bundle remains a separate
Prospector-owned pin; raw papers and unverified redistribution assets are absent.
